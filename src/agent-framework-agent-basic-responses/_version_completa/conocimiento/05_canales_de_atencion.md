# Canales de atención – MALI Educación
Fuentes: https://www.mali.pe/, https://educacion.mali.pe/ y sus páginas internas (consultados el 10/10/2026)

## Correo de cursos de arte e informes
Para consultas sobre cursos de arte, el MALI publica el correo cursosdearte@mali.pe.

## Mesa de partes virtual y trámites
La mesa de partes virtual de MALI Educación atiende en mesadepartesvirtual@mali.pe.

## Visitas educativas, colegios y universidades
Para experiencias educativas (colegios, instituciones de nivel superior, visitas grupales, CumpleMALI) el correo de atención es visitaseducativas@mali.pe.

## Arte Empresa y servicios para empresas
Para cursos y talleres para colaboradores de empresas, la página de Arte Empresa indica como contacto de atención rjara@mali.pe.

## Datos personales y privacidad
Para revocar la autorización de uso de datos personales o modificarlos, el correo es datos@mali.pe.

## Reclamos
El MALI cuenta con un Libro de reclamaciones en https://mali.pe/es/libro-de-reclamaciones.

## Campus virtual
El Campus Virtual de MALI Educación está en https://campusvirtual.mali.pe/.
