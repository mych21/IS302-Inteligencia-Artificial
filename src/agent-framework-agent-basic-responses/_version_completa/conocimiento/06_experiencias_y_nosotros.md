# Experiencias educativas, Arte Empresa y propuesta de MALI Educación
Fuentes: https://educacion.mali.pe/experiencias-educativas/, https://educacion.mali.pe/arte-empresa/, https://educacion.mali.pe/nosotros/ (consultados el 10/10/2026)

## Propuesta de MALI Educación
El MALI ofrece cursos de diversas ramas artísticas para niños, jóvenes y adultos: artes plásticas, artes gráficas, artes manuales, artes vocales, artes musicales, artes escénicas y bailes. La propuesta destaca el aprendizaje activo y personalizado, docentes especializados con amplia experiencia, y la disponibilidad de clases online.

## Experiencias educativas para colegios e instituciones
El área de Experiencias Educativas diseña visitas y talleres para colegios (estudiantes y docentes), visitas personalizadas para instituciones de educación superior, visitas grupales, experiencias en familia y celebraciones de cumpleaños (CumpleMALI). Las visitas se agendan mediante el calendario de reservas.

## Arte Empresa y vacaciones útiles
Arte Empresa ofrece cursos para colaboradores (en sedes del MALI, en la empresa o virtuales), talleres de integración, talleres para la comunidad como parte de la responsabilidad social, y el programa de vacaciones útiles VeraneArte (enero y febrero) para hijos de colaboradores.
