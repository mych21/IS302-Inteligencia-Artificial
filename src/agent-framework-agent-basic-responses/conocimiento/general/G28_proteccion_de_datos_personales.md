# Protección de datos personales
Colección: Términos y condiciones de MALI Educación (2026)
Fuente: https://educacion.mali.pe/wp-content/uploads/2026/01/Uso_de_datos_Terminos_y_condiciones_Mali_Educacion_2026.pdf (consultado el 10/10/2026)
Nivel de acceso: general
Responsable: Coordinación Académica (prototipo)
Vigente hasta: 31/12/2026

De acuerdo con la Ley 29733, Ley de Protección de Datos Personales, al inscribirse el usuario autoriza el tratamiento de sus datos para fines como información de la oferta educativa, seguimiento de la inscripción, encuestas, y fines administrativos y estadísticos, con estricta confidencialidad. El usuario puede revocar la autorización o modificar sus datos escribiendo a datos@mali.pe.
