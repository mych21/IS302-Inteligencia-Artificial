# Perfiles y gestión de alumnos en el asistente
Colección: Procedimientos del prototipo MALI Asistente
Fuente: Documento del proyecto MALI Asistente (IS302, UPC 2026-2)
Nivel de acceso: general
Responsable: Coordinación Académica (prototipo)
Vigente hasta: 31/12/2026

Para usar el asistente primero se inicia sesión con la cuenta institucional; antes de cada consulta se verifica el perfil y sus permisos. El asistente reconoce cuatro perfiles: Estudiante, Personal administrativo y docente, Coordinación Académica y Soporte de TI. Todos pueden consultar la base general (cursos, procedimientos, vacantes y canales). La gestión de alumnos (matrícula, asistencia y situación administrativa) solo está disponible para la Coordinación Académica y para el personal que esta habilite. Soporte de TI no consulta datos de alumnos, pero puede revisar el registro de consultas junto con la Coordinación, que además actualiza los datos y decide quién accede. Los datos de alumnos del prototipo son sintéticos y se identifican con un código interno (ALU-0001), sin nombres ni documentos de identidad.
