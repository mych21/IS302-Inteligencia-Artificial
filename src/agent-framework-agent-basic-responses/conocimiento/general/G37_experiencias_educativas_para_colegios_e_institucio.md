# Experiencias educativas para colegios e instituciones
Colección: Experiencias educativas, Arte Empresa y propuesta de MALI Educación
Fuente: https://educacion.mali.pe/experiencias-educativas/, https://educacion.mali.pe/arte-empresa/, https://educacion.mali.pe/nosotros/ (consultados el 10/10/2026)
Nivel de acceso: general
Responsable: Coordinación Académica (prototipo)
Vigente hasta: 31/12/2026

El área de Experiencias Educativas diseña visitas y talleres para colegios (estudiantes y docentes), visitas personalizadas para instituciones de educación superior, visitas grupales, experiencias en familia y celebraciones de cumpleaños (CumpleMALI). Las visitas se agendan mediante el calendario de reservas.
