# Aviso de privacidad del asistente
Colección: Procedimientos del prototipo MALI Asistente
Fuente: Documento del proyecto MALI Asistente (IS302, UPC 2026-2)
Nivel de acceso: general
Responsable: Coordinación Académica (prototipo)
Vigente hasta: 31/12/2026

MALI Asistente es un prototipo académico. Las conversaciones se usan solo para orientar sobre cursos y procedimientos. El asistente no solicita tarjetas, contraseñas ni datos de salud. Solo al inscribirse pide nombre, número de documento, teléfono y correo, que se guardan en la base restringida y solo consulta el personal autorizado. Las consultas a la base restringida quedan registradas con fecha, perfil, tipo de consulta y fuente, sin guardar el texto de la conversación. Para menores de edad, la inscripción real requiere a sus padres o tutores. Para ejercer derechos sobre datos personales (Ley N.º 29733) se escribe a datos@mali.pe.
