# Pre-inscripción de demostración
Colección: Procedimientos del prototipo MALI Asistente
Fuente: Documento del proyecto MALI Asistente (IS302, UPC 2026-2)
Nivel de acceso: general
Responsable: Coordinación Académica (prototipo)
Vigente hasta: 31/12/2026

La pre-inscripción del prototipo sigue cuatro pasos: elegir el curso, elegir el horario, indicar nombre completo y correo, y confirmar con «sí» o cancelar con «no». Al confirmar se genera un código de demostración (MAT-0001, MAT-0002…) y se descuenta una vacante del archivo de demostración. No es una matrícula oficial: la matrícula definitiva y el pago se realizan por el canal oficial cursosdearte@mali.pe. El asistente nunca pide DNI, tarjetas ni contraseñas.
