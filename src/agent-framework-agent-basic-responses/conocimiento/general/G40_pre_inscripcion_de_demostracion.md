# Pre-inscripción de demostración
Colección: Procedimientos del prototipo MALI Asistente
Fuente: Documento del proyecto MALI Asistente (IS302, UPC 2026-2)
Nivel de acceso: general
Responsable: Coordinación Académica (prototipo)
Vigente hasta: 31/12/2026

La inscripción del prototipo sigue cinco pasos: elegir el curso, elegir el horario, indicar nombre completo, número de documento, teléfono y correo, confirmar con «sí» (o cancelar con «no») y enviar el código de pago de la operación (formato PAG-000000). Al confirmar se genera un código de pre-inscripción (MAT-0001, MAT-0002…) y se descuenta una vacante; al validar el código de pago, la inscripción queda completada y el asistente muestra el horario y la información del curso. Si el pago se hace después, se escribe «pago MAT-0001 PAG-100001». Si el código de pago aún no figura en los pagos conciliados, la inscripción queda «por confirmar»: la vacante sigue separada y el personal del MALI aprueba o rechaza el pago; el estado se consulta escribiendo «estado de mi matrícula», luego el código de alumno (ALU-0000) y, para verificar la identidad, el número de documento dado al inscribirse; el asistente no muestra el documento, el teléfono ni el correo. Los códigos de pago y las inscripciones son de demostración: la matrícula real se realiza por el canal oficial cursosdearte@mali.pe. El documento y el teléfono solo se piden en este paso y solo los ve el personal del MALI; el asistente nunca pide tarjetas ni contraseñas.
